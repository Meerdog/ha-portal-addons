# Nate's Home Assistant add-ons

Add this repository in Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories**, then paste
`https://github.com/Meerdog/ha-portal-addons`.

| Add-on | What it does |
|---|---|
| [Home Portal](portal/DOCS.md) | Serves pages and engines Claude publishes to `Meerdog/portal-content`, sandboxed, with a home page of cards. |

Code only; no secrets live here. Published content lives in the private `portal-content` repo.
